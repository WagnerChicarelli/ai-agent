# Sobre o AI Agent

O AI Agent é um assistente de inteligência artificial construído com Node.js e LangChain.js.

## Funcionalidades

1. **Chat Interativo** - Converse com o agente via linha de comando
2. **Busca Web** - Encontre informações atualizadas na internet
3. **Sistema de Arquivos** - Leia e escreva arquivos
4. **RAG** - Busque em documentos carregados

## Tecnologias

- **Node.js** - Runtime JavaScript
- **TypeScript** - Tipagem estática
- **LangChain.js** - Framework para LLMs
- **Ollama** - LLM local e gratuito
- **llama3.1** - Modelo de linguagem
- **mxbai-embed-large** - Modelo de embeddings

## Como usar

Para iniciar o agente, execute:

```bash
npm run dev
```

O agente irá aguardar suas instruções no terminal.
