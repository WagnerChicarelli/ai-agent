# Guia de Ferramentas

## web_search

A ferramenta de busca web utiliza o DuckDuckGo para encontrar informações.

**Uso:** Pergunte sobre qualquer assunto e o agente buscará na web.

**Exemplo:** "Quem é o presidente do Brasil?"

## read_file

Lê o conteúdo de arquivos no sistema.

**Uso:** Solicite para ler um arquivo específico.

**Exemplo:** "Leia o arquivo README.md"

## write_file

Cria ou atualiza arquivos.

**Uso:** Solicite para criar um novo arquivo ou modificar um existente.

**Exemplo:** "Crie um arquivo chamado notas.txt com o conteúdo 'Minhas anotações'"

## load_documents

Carrega documentos para o vector store.

**Uso:** Forneça o caminho de um arquivo ou diretório.

**Exemplo:** "Carregue os documentos da pasta data/docs"

## search_documents

Busca informações nos documentos carregados.

**Uso:** Faça perguntas sobre os documentos.

**Exemplo:** "O que diz sobre as tecnologias usadas?"
